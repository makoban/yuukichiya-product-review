# 勇吉屋 商品確認

ログイン不要の商品の確認画面。商品画像・登録元・商品名を候補ごとに並べ、まとめて確認できます。

- 初期対象：2024年10月1日〜2026年9月30日のAirレジ販売実績あり。
- 販売のない採寸・学校販売・BASEも、対応候補として比較します。
- 回答は共有保存し、途中から再開できます。別端末の進み具合も5秒ごとに更新します。
- 顧客情報、販売数量、原価、在庫、秘密情報は含めません。
- ここで回答してもAirレジ・BASEの商品・在庫・価格は変更されません。
- 対象は2026年10月2〜3日取得のAir6区分と公開BASE619商品。非公開BASEは対象外です。

GitHub PagesのURL： https://makoban.github.io/yuukichiya-product-review/

このURLはアクセス制限のない公開ページです。検索への掲載はnoindexで控えますが、アクセス制限ではありません。

共有保存は既存の購入履歴サービスの専用公開APIを使用します。認証付きの商品確認・予約・管理画面とは別の回答データです。確認者名は入力せず、匿名の端末番号だけ記録します。
